🔄 Saga Pattern & Distributed Transactions

Minh họa cơ chế điều phối giao dịch phân tán (Choreography Saga) qua RabbitMQ giữa Order Service và Payment Service cùng hành động bồi hoàn khi thanh toán thất bại.

1

Khách hàng tạo đơn hàng (Order Creation)

API Gateway -> Order Service: Tạo đơn hàng trạng thái PENDING, đồng thời khóa và giữ kho bằng Redis Distributed Lock.

HTTP / REST
2

Phát sự kiện OrderCreatedEvent lên RabbitMQ

Order Service gửi event tới Topic Exchange ecommerce.exchange (Routing Key: order.created). Notification Service và Payment Service tự động nhận diện.

RabbitMQ Topic
3

Xử lý thanh toán cổng VNPay Sandbox (Payment Step)

Payment Service nhận event và tạo giao dịch thanh toán. Người dùng xác nhận thanh toán thành công hoặc giả lập hủy/thất bại.

Payment Gateway
4

Hành động Bù (Compensating Transaction) nếu Thanh toán Thất bại

Nếu thanh toán bị hủy -> Payment Service phát payment.failed -> Order Service tự động HOÀN TRẢ TỒN KHO và chuyển đơn sang CANCELLED.

Saga Rollback
